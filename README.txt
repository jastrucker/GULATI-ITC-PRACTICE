GULATI ITC PRACTICE - Android starter project

This is the initial Android Studio project, not a compiled APK.
It contains the app shell and navigation for:
- Horizontal Streets
- Vertical Streets
- Arabic Words
- Mock Test

IMPORTANT:
The uploaded Aman Taxi PDF is scanned and its text was not automatically readable.
No questions or answer keys have been invented. The verified question bank must be
transcribed from the scanned pages before quiz mode can be populated.

BUILD:
1. Install Android Studio on a computer.
2. Open this project folder in Android Studio.
3. Allow Gradle sync and install the Android SDK (API 35) if prompted.
4. Choose Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Android Studio will create the APK in app/build/outputs/apk/debug/.

The project requires internet during the first Gradle sync to download Android build tools.
After installation, the app shell itself does not need internet.
